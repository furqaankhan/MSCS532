# Assignment 1: Insertion Sort

This assignment implements Insertion Sort in Python. It sorts numbers in descending order, from largest to smallest.

Run the examples with:

```bash
python3 assignment_1/insertion_sort.py
```

Example output:

```text
Original: [5, 2, 9, 1, 5, 6]
Sorted:   [9, 6, 5, 5, 2, 1]
```
