# Assignment 2: Merge Sort and Quick Sort

This assignment implements Merge Sort and Quick Sort in Python. Both sort numbers in ascending order.

Run the examples from the repository root:

```bash
python3 assignment_2/algorithms.py
```

Compare execution time and extra memory on sorted, reverse-sorted, and random data:

```bash
python3 assignment_2/benchmark.py
```

The comparison uses five input sizes and five runs per case, and prints median results. It may take a few minutes. Memory is measured separately and excludes the input list. Python 3 is required; no additional packages are needed.
